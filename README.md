# The Spice Table — Restaurant Website

A responsive single-page restaurant website with:
- Hero section and restaurant branding
- Filterable menu categories
- Dish cards with sample descriptions and INR prices
- Chef's special section
- Guest review cards
- Reservation form that can be connected to WhatsApp
- Responsive mobile layout

## Run it
Open `index.html` in a browser. Internet is required for the Google Fonts and Unsplash food photos.

## Customize before publishing
1. Replace **The Spice Table** with the actual restaurant name.
2. Update address, opening hours and phone number in the Find Us section.
3. Replace sample menu items, descriptions and prices with the real menu.
4. Replace the sample reviews with genuine reviews only.
5. In `index.html`, find `const restaurantWhatsApp = '919876543210';` and replace it with the restaurant's WhatsApp number including country code, without `+` or spaces.
6. Replace the photos if you have real restaurant/food photography.

## Publish
You can upload `index.html` to GitHub Pages, Netlify, or any static website host. No build tools are required.
